# RoboFleet – Autonomous Robot Fleet Management System

## 1. Project Description
RoboFleet is a robot fleet management application developed using Python, Streamlit, and MySQL. It simulates a warehouse environment where multiple virtual robots are managed, assigned tasks, and monitored through a centralized dashboard.

## 2. Problem Statement
Manual robot management can cause inefficient task allocation, poor resource utilization, and difficulty in monitoring robot status. RoboFleet aims to improve robot management through automation and the application of Operating System (OS) and Database Management System (DBMS) concepts.

## 3. Objectives
- Automatically assign tasks to suitable available robots.
- Monitor robot status, battery levels, and task progress.
- Implement task scheduling, preemption, and resource management.
- Detect and handle resource deadlocks.
- Store and manage robot and task information using MySQL.
